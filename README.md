Project description :
CV Matcher is an application that compares a CV with a job description
to help candidates tailor their applications.
 
Its goal is to identify matching skills, missing keywords, and areas
for improvement in the CV.
 
Planned Features :
 
- Upload a CV and enter a job description.
- Compare the candidate’s skills with the job requirements.
- Display a match score.
- Identify missing skills and keywords.
- Suggest ways to improve the CV.
