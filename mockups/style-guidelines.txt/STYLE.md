CV MATCH - STYLE GUIDELINES
 
1. Overview

CV Match is a clean and simple web tool that helps users check their CV against job postings. The design relies on a fresh mint green and deep navy color scheme for a modern look.
 
2. Colors

- Main Navy (Header & Accent text): #0B2B26

- Primary Mint Green (Buttons & Highlights): #34D399

- Dark Teal (Main Action Buttons): #0A5C5A

- Page Background: #F8FAFC

- Card Backgrounds: #FFFFFF

- Text Color: #0B2B26 (Headings) / #64748B (Body text)
 
3. Typography

- Font Family: 'Inter', Arial, sans-serif

- Headings: Bold, sizes ranging from 20px (cards) to 44px (hero text)

- Body Text: 16px Regular with good line height for readability
 
4. Buttons & Components

- Buttons: Rounded pill-shaped corners (20px border radius) with solid teal or green backgrounds and white text.

- Cards: White background with rounded corners (16px) and subtle soft shadows.

- Text Boxes: Clean 1px gray borders that highlight green when clicked.
 
5. Layout

- Centered layout with a max width of 1200px.

- Uses flexbox and CSS grid to stay responsive on screens of all sizes.
